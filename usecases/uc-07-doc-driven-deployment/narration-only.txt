==========================================================================

Today, turning a requirement into a running application takes days. Someone reads the document, writes about two thousand lines of YAML by hand, gets it reviewed, deploys it - and hopes.

And when the pods go green, nobody actually proves the application works. The first real test is a user hitting a broken page.

The App Deployment Agent removes every step except the decisions.
