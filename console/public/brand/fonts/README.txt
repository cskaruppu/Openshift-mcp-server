Houschka Rounded Alt — web font files go here.

The console already uses Houschka Rounded Alt wherever it is installed on the
viewer's machine. To serve it to every browser, place the licensed web-font
files here under exactly these names, then redeploy the dashboard:

  houschka-rounded-alt-regular.woff2    (text weights, 400)
  houschka-rounded-alt-demibold.woff2   (headings, tabs, buttons, 600)
  .woff versions of each are optional fallbacks

Check the licence covers web embedding (a "webfont" licence) before adding
them. Nothing else needs to change: styles.css already points here.
