The Challenge: Manual Cluster Upgrades

OpenShift cluster upgrades are one of the most time-intensive, risk-prone, and repetitive operations in enterprise container platform management. Organizations running 10–50+ production clusters face compounding operational burden every upgrade cycle.

Time-Intensive Process

Each upgrade requires 14–40 hours of cumulative SRE time spread across 2–5 business days, including pre-checks, approvals, execution, monitoring, and documentation.

Human Error Risk

Manual health checks miss edge cases — expired certificates, deprecated APIs, under-replicated etcd members, and storage pressure go undetected until mid-upgrade.

Compliance Gaps

Change Requests are often incomplete, post-assessment documentation is inconsistent, and audit trails have gaps — leading to compliance findings during SOC2/ISO audits.

Operational Bottleneck

Senior SREs are pulled from high-value work to babysit upgrade progress, manually checking operator health and node readiness every few minutes for hours.

How It Works

TCS Agentic AI deploys a hub-spoke architecture where the central orchestrator (hub) coordinates with lightweight spoke agents running on each managed cluster. The AI engine drives a 10-state state machine that autonomously progresses through the upgrade lifecycle:

  • AI Pre-Assessment — Runs 50+ health checks in parallel: operator status, node conditions, etcd quorum, certificate expiry, deprecated API usage, PDB violations, storage capacity, and network connectivity
  • Intelligent Remediation — Identifies blockers and proposes targeted fix actions with risk scoring before upgrade begins
  • ITSM Integration — Auto-generates ServiceNow Change Request with PDF/HTML assessment reports, risk classification, rollback plan, and implementation steps
  • Approval Gate Automation — Continuously polls ServiceNow for CR approval, auto-advances when approved
  • Safe Execution — Performs dry-run validation, then initiates CVO-driven upgrade with real-time 15-second progress polling
  • Smart Completion — Upgrade completes only when all three conditions are met: ClusterVersion history confirmed, all operators healthy, all nodes ready
  • Post-Assessment & Close — Generates comprehensive post-upgrade report, auto-closes CR with detailed close notes including timing, operator counts, and node health

Built-in Safety & Risk Mitigation

Stalled Upgrade

CVO progress stuck at a percentage for extended time

Mitigation: 15-second polling detects stall, alerts SRE, provides operator-level diagnostics
Operator Degradation

ClusterOperator enters degraded state during upgrade

Mitigation: Real-time operator health tracking, AI analysis of degradation cause, rollback guidance
Node Not Ready

Worker or master node fails to rejoin after reboot

Mitigation: Node-level health monitoring, machine config pool status tracking, drain/cordon detection
False Completion

Upgrade appears done but operators still reconciling

Mitigation: Triple-condition gate — ClusterVersion history confirmed AND all operators healthy AND all nodes ready
Approval Delay

ServiceNow CR approval takes longer than expected

Mitigation: Continuous auto-polling, state machine pauses safely at approval gate without timeout
Pre-Assessment Miss

Edge-case health issue not caught before upgrade

Mitigation: 50+ parallel checks covering operators, nodes, etcd, certs, APIs, storage, PDBs, networking

Integration Architecture

Hub-Spoke Multi-Cluster Architecture

  • Hub (Control Plane) — Central orchestrator with AI engine, state machine, ServiceNow integration, report generation, and unified dashboard
  • Spoke Agents — Lightweight agents deployed on each managed cluster via auto-generated Kubernetes YAML; stateless, no database required
  • ServiceNow — Bidirectional integration for Change Request lifecycle (create → approve → work notes → close)
  • Real-Time Dashboard — Live upgrade progress with CVO percentage, operator health, node readiness, and timing metrics
  • PDF & HTML Reports — Auto-generated pre-assessment and post-assessment reports attached to ServiceNow CR
